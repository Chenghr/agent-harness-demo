# 多人祝福文案编辑

读取实际成员数组，以姓名作为稳定标识。

- 先保存每位成员原文，再处理用户明确指定的成员。
- 未被点名的成员逐字保留，不做统一润色。用户没有设置字数限制时，不以“更简洁”为由主动压缩。
- 小艺新人导师感谢场景中，检查文字是否自然覆盖工作方法或专业成长，以及生活关怀或团队融入；缺项时只报告，不自行虚构经历补齐。
- 字数按 Unicode 字符逐个计数，标点也计入；同时可单独报告汉字数，不能混用。
- 压缩时保留原文核心含义，不新增人物经历、称谓或事实。
- 输出完整成员数组、被修改成员的修改前后文本、字符数和未修改名单。
- 不写回源文件，除非用户另行明确要求并通过文件授权。

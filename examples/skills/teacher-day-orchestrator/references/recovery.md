# 有限恢复策略

- `429`、`502`、`503`、`504`：运行时会先做有界退避；工具仍失败时，只为对应成员新建一次重做助手。
- 子任务达到总时限：保留其已经成功的图片；单人图片助手超时时只重做该成员。不要通过把多人塞回同一个子任务来减少节点数。
- 内容或风格不合格：保留旧版本，只重做被指出的成员；不得重生成其他成功图片。
- 成员缺失、重复、文案超限、图片不是当前版本：`greeting_site` 应拒绝生成，先修输入再创建新预览。
- 页面或后端中断：先读取现有任务、图片和预览状态，不自动重放可能已经产生外部副作用的操作。
- 发布结果不确定：到发布服务核对，不重复提交。

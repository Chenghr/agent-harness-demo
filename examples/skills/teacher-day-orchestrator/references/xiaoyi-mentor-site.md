# 小艺新人导师感谢网站规范

## 背景

八位华为小艺入职新人都有对应导师。网站在教师节表达对导师的感谢，既呈现工作上的方法指导、反馈与成长，也呈现生活中的关心、陪伴与团队融入。不要编造导师姓名、具体项目或未经提供的个人事件。

头像性别必须读取 `members.json` 的 `gender` 字段，不根据姓名判断：周雨宸、韩舒羽为女性；程浩然、沈希扬、王子康、时泽润、汤其政、王默涵为男性。创建每个图片助手时都在背景和出图描述中明确传递对应性别。

## 固定文案

- 标题：小艺新程 · 师恩相伴
- 副标题：八位小艺新人，以文字记录入职以来的成长与收获，感谢导师在工作上的悉心指导，也感谢生活中的关心与陪伴。
- 开场引言：从校园走进职场，从陌生走向熟悉，每一次耐心解答、每一句真诚鼓励，都让我们的新旅程更有方向。值此教师节，我们把八份感谢写进同一个页面，献给一路引导和陪伴我们的导师。
- 感谢信栏目标题：八封写给导师的信
- 结尾标题：新程有您，步履更坚定
- 结尾寄语：感谢您以经验为灯，也以关怀为伴。未来我们会带着这份耐心与认真继续成长，把得到的帮助化为做好每一件事的行动。

## 页面栏目

1. 首屏：标题、副标题、开场引言与“8 位新人 / 8 份感谢 / 共同成长”信息。
2. 成长的四个切面：
   - 工作上手：从理解目标到掌握方法，导师帮助新人更快找到节奏。
   - 专业成长：在反馈、复盘和实践中，逐渐建立判断与信心。
   - 团队融入：理解协作方式，在坦诚沟通中成为可靠的伙伴。
   - 生活关怀：忙碌之外的问候与陪伴，让新的环境更有温度。
3. 成长路径：初见、上手、成长、同行。它是抽象叙事，不声称发生过具体事件。
4. 八封感谢信：保持 `members.json` 的姓名顺序和完整文案，每人配一张明确分配的图片及一个内容关键词。
5. 共同寄语：使用固定结尾标题和寄语。

成员关键词依次使用：耐心引路、温暖守护、授人以渔、坚定鼓励、标准与方法、理解与担当、陪伴成长、细致关怀。

# 小艺新人导师感谢网站编排

先读取实际成员材料和网站验收要求，再组织工作。不要把计划当成结果。

- 文案、视觉、音乐和视频按阶段顺序推进；上一阶段交接物明确后再进入下一阶段，任务树保持稳定易读。
- 每位成员使用一个独立图片助手；一个图片助手只生成一位成员的一张图片，不在同一子任务中串行处理第二位成员。
- 图片助手按服务容量滚动派发。未明确容量时每批最多两个，等待本批结束后再创建下一批，避免排队时间占满子任务总时限。
- 子助手只接收完成其任务所需的成员、文案、模型编号和视觉规范。
- 单项失败不取消成功项。运行时先处理临时限流；仍失败或单人子任务超时时，只为该成员创建一次重做助手，仍失败则停止组装并报告。
- 八张成功图片必须以明确版本 ID 分配给搭站助手。
- 音乐和视频分别由一个 `media` 助手生成；各只调用一次对应生成工具。视频已返回远程任务 ID 但结果未知时停止并报告，不能重复提交。
- 成功的音乐与视频版本必须通过 `agent_spawn.media` 明确分配给搭站助手。
- 搭站完成后把固定预览明确分配给独立检查助手。检查未通过时只返工对应成员或文案，然后重新生成预览并复检。
- 模型可以申请发布，但不能代替用户批准。没有发布配置时停在本地预览。

执行本案例时先读取 [references/xiaoyi-mentor-site.md](references/xiaoyi-mentor-site.md) 获取业务背景、固定标题和网站栏目，再读取 [references/workflow.md](references/workflow.md)。音乐策划加载 `mentor-music-director`，视频分镜加载 `mentor-video-storyboard`。只有出现失败或返工时再读取 [references/recovery.md](references/recovery.md)。

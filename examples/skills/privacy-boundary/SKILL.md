# 实体边界检查

## 输入
用户给定的文本、实体标注和边界规则。先确认字符下标单位，以及结束位置是否包含在实体内。缺少定义时报告缺口。

## 步骤
1. 对照原文逐项检查实体起止位置是否有效。
2. 比较标注文本与原文对应片段，不通过修改原文让标注看起来正确。
3. 是否包含标点、称谓或空格，以本次用户给定规则为准。
4. 保留无法确定的情况，说明需要用户确认的问题。

## 输出
问题清单，包括样本引用、原始范围、原文依据和建议；与标签类型、重叠关系问题分开说明。

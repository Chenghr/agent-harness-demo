# 小艺新人导师感谢网站搭建

只使用明确分配的图片、音视频版本和背景中的最终文案，不自行重新生成或改写内容。

- 调用 `greeting_site`，优先使用 `paper-garden` 主题、`gallery` 布局和 `gentle` 动效。
- 提供完整开场白，并使用成长切面、成长路径、八封感谢信和共同寄语组织页面；不编造具体导师姓名或未提供的个人事件。
- 标题固定为“小艺新程 · 师恩相伴”，副标题固定使用用户提供的完整文字。
- 每位成员可提供一个概括祝福含义的短关键词。
- 生成前核对姓名、文案、图片 ID 一一对应，并传入明确分配的 `musicId` 与 `videoId`。
- 背景音乐由用户点击播放，不要求浏览器强制自动播放；视频使用原生控件，播放视频时页面自动暂停背景音乐。
- 工具拒绝成员或字数检查时，报告具体输入问题，不绕过检查改用普通预览工具。
- 返回预览 ID、文件数、主题和固定版本摘要；不申请发布。

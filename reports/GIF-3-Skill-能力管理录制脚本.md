# GIF 3：Skill / 能力管理录制脚本

## 要证明的一句话

1,200+ Skill 可以分层管理和精确检索；任务只加载当前需要的一项，不把整座目录塞进 Prompt，用完即可卸载。

## 演示案例

业务情境：大促结束后，需要分析电商订单数量的首尾变化。从千级能力目录中找到“电商数量首尾变化分析”，只加载到当前主助手，检查活跃能力从 0 变为 1，再卸载回 0。

使用内置教学 Skill：

```text
名称：电商数量首尾变化分析
调用名：commerce-volume-trend
目录：教学规模样本 / 电商
```

不需要额外文件、API Key 或真实模型。

## 录制前准备

1. 打开 `http://127.0.0.1:4318` 并刷新。
2. 建议窗口宽度 1440px 左右、浏览器缩放 90% 或 100%。
3. 清空鼠标附近无关提示，录制区域覆盖左侧导航、主区域和运行详情。
4. 使用全新任务；旧任务可能已经加载过其他 Skill。

## 推荐镜头顺序（约 35 秒）

### 镜头一：分层目录，6 秒

1. 点击左侧“能力管理”。
2. 在“分类目录”根层停留，拍到“教学规模样本”目录及其千级条目数量。
3. 依次进入“教学规模样本 → 电商”。
4. 将类型筛选为“Skill”，拍到电商分支中的分页能力列表。

画面字幕：

```text
1,200+ Skill 按场景分层管理，无需一次注入模型上下文
```

### 镜头二：建立干净任务，5 秒

1. 返回工作台，点击“新建任务”。
2. 模型选择“Demo · 标准”。
3. 点击演示任务“Skill 按需加载”。
4. 打开“运行详情 → 工具”，拍到 `Skill 0`。

画面字幕：

```text
新任务初始活跃 Skill：0
```

### 镜头三：精确检索并加载，12 秒

1. 点击顶部“能力目录”或工具面板中的“搜索目录”。
2. 切换到“Skill”。
3. 搜索：

```text
commerce-volume-trend
```

4. 选中“电商数量首尾变化分析”，停留 2 秒，拍到来源、调用名和完整说明。
5. 点击“加载到主助手”，关闭目录窗口。
6. 拍到工具面板从 `Skill 0` 变为 `Skill 1`，且只出现 `commerce-volume-trend`。
7. 在“最近调用”中打开 `skill_load`，拍到加载名称、版本、来源以及 `permissionGranted: false`。

画面字幕：

```text
精确检索，只将当前需要的 1 项加载到主助手
```

### 镜头四：卸载，7 秒

1. 点击 `commerce-volume-trend` 标签右侧的关闭按钮。
2. 拍到 `Skill 1 → 0`。
3. 在“最近调用”中拍到 `skill_unload` 与“历史继续保留”的结果。

画面字幕：

```text
用完即卸载；停止后续 Prompt 注入，既有历史仍可追溯
```

### 结尾定格，3 秒

```text
千级目录 ≠ 千项 Prompt
按需发现 · 按需加载 · 用完卸载
```

## 关键画面清单

- “教学规模样本”目录显示千级条目数。
- 工作台能力目录显示 1,200+ Skill 总量。
- 加载前 `Skill 0`。
- 搜索结果唯一命中 `commerce-volume-trend`。
- 加载后 `Skill 1`，只有一个标签。
- `skill_load` 的真实调用参数与结果。
- 卸载后 `Skill 0`。
- `skill_unload` 显示历史保留。

## PPT 旁白

“系统只把目录概述和基础发现工具提供给 Agent。Agent 或用户先沿分层目录缩小范围，再检索具体能力。选中的 Skill 才会按固定版本注入当前 Agent，并受活跃数量与上下文容量限制；卸载后停止后续注入，原有执行记录仍然保留。”

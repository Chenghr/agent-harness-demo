# 5-桌面宠物与界面说明

本轮把宠物作为一个能查看进展、解释任务和接收用户反馈的小助手，名字为“小伴”。它与主任务分开工作，避免聊天和情绪反馈影响任务执行。

## 它能做什么

小伴显示所选任务的状态、最近工具操作、成功与失败次数、子任务数量。等待授权、检查成果、完成或失败都来自实际运行状态，不编造完成百分比。

用户可以单独与它对话。真实模型模式下，它能只读检索主任务历史，解释发生了什么，也可以轻量闲聊。模拟模式只返回进展与关键词匹配结果，明确说明不具备自由对话理解能力。

页面角落的小伴关注当前任务；独立窗口和 macOS 浮窗可以跟随工作台，也可以固定查看一个任务。展开后显示对话和证据，收起后只显示角色与简短状态。安静陪伴模式隐藏收起时的状态气泡；动画遵守系统的减少动态效果偏好。

角色由本项目自己的 SVG 和动画实现，包含呼吸、眨眼、工作、点赞跳动和鸡蛋反应，不依赖外部图片服务，也不是安装到 Codex 中的宠物资源包。

## 对话与主任务分开

小伴有独立的消息文件和模型请求。它不调用主任务的 Agent Loop，不改变用户要求，不申请文件写入，不创建子任务，也不替用户批准操作。

每个问题固定使用开始时选定的模型。输入包括读取时刻的进展、近期宠物对话及检索证据，按该模型的输入容量检查。真实模式最多进行三轮只读查询，最后一轮只回答；每轮最多四个查询请求。模型提出其他工具调用时会被拒绝。

历史结果带原始序号，页面可以展开证据，再分段读取原始记录。模型引用不存在的序号时标记为未核实。来源可查并不等于解释必然正确；回答是读取时的快照，主任务仍可能继续推进。

宠物每个任务只接受一个在途回答，宠物之间另有单独的并发限制，不占主任务模型队列。可以单独停止宠物回答；关闭请求连接或服务时会取消相应请求。停止主任务后仍可向宠物询问已有记录。

## 点赞、点踩和扔鸡蛋怎样保存

用户先选择反馈对象：整个任务、主助手最近回答、最近一次工具操作，或某一条小伴回答。可以补充原因，再点赞、点踩或扔鸡蛋。角色给出轻量反馈，不说教，也不把情绪反应当成新的任务指令。

记录包含反馈类型、原因、对象、对象快照、模型、任务及工作区版本、执行轮次和时间。对象必须属于当前任务。这样导出后能知道用户评价的是什么，不只剩一个脱离上下文的分数。

这些记录是软标签：点踩可能是回答错误，也可能是解释不清、速度慢或期待不一致。它们不会自动改变成果验收、Skill 评分、权限或模型参数。

记录默认保存在本机，可导出 JSON，也可单独清空本任务的宠物记录。清空不会删除主任务。macOS 浮窗的导出入口打开本地网页，由网页完成文件下载。没有自动上传、自动训练或已经跑通的模型迭代闭环。

真实模型模式下，提问与需要的历史片段会发送到用户配置的模型服务；页面对此有提示。“反馈保存在本机”不代表模型请求也完全离线。

## 前端怎样呈现

主界面改成简洁的浅色工作台。左侧是任务列表和能力管理，中间是对话与成果入口。右侧任务树、工具、上下文、事件和产物按需打开，默认收起。演示场景折叠在入口下，减少首页同时出现的大量指标和机制名称。

宠物占据右下角的小区域，不替代主对话。能力库仍是独立管理页面。模型的模拟／真实状态、授权按钮、成果检查和错误提示继续保留，界面简化不隐藏必要的决策信息。

工作示例新增“隐私实体数据集”：对三条合成文本按给定规则生成标注，写入前授权，运行时重新读取结果检查原文、标签、边界和空样本。包含 emoji 的码点计数。该数据和自动检查只属于教学示例，不代表通用标注格式或真实模型的标注质量。

## 桌面运行和代码边界

先启动本地服务，再运行：

```bash
npm run desktop
```

需要 macOS 和可用的 Swift 编译器。脚本在 `.desktop/HarnessPet.app` 构建应用，连接本机 Web 服务。默认端口 4317；其他端口可以用 `PORT=4329 npm run desktop`。`npm run build:desktop` 只编译。菜单栏支持显示、隐藏和退出；浮窗支持收起、展开及拖动。

桌面壳只允许连接本机宠物页面。网页到桌面的接口只操作它自己的窗口和本地网页入口，没有文件、终端或模型密钥接口。密钥继续留在服务端。

实现分为 `server/companion.mjs` 的独立服务、`server/context/history.mjs` 的共用只读检索、`web/app/components/companion.tsx` 的界面，以及 `desktop/Pet.swift` 的 macOS 窗口。其他系统可使用 `/pet/` 独立网页，本轮未制作 Windows 或 Linux 原生桌面程序。

验证覆盖独立历史、反馈对象范围、请求取消、窗口断连、HTTP 导出清空、模型容量与原有主任务功能。macOS 浮窗已实际打开并检查收起、重新展开和退出。真实模型的闲聊与解释质量尚未作为真实服务测试结论。
